EX2:

Heading 1 is used for main sections and should be applied once per section. Heading 2 is for subheadings under Heading 1. "Restart numbering" resets list numbering for new sections. A Table of Contents (TOC) lists sections and is generated from heading styles. Update the TOC via the References Tab to reflect document changes.


EX3:



1. Bulleted List vs. Numbered List: A bulleted list uses symbols (e.g., dots) to organize items without implying a sequence, while a numbered list uses numbers to indicate a specific order or sequence.

2. Find Command: The Find Command is used to locate specific text or characters within a document.

3. Elements in Header and Footer: Elements that can be inserted in a document's header and footer include page numbers, date and time, document title, author name, and company logo.

4. Footnote vs. Endnote: Footnotes appear at the bottom of the page where the reference is made, while endnotes appear at the end of the document or section.

5. Document Margins: Document margins are the blank spaces around the edges of a page, defining the area where text and content can be placed.


EX4:


3. Table of Contents (TOC): A TOC lists the titles and page numbers of the document's sections and subsections, generated from the styles applied (e.g., Heading 1, Heading 2). It can be updated via the References Tab by selecting Update Table, choosing "Update page numbers only" or "Update entire table."

4. Numbering Figures: Figures can be numbered by inserting captions and using the Insert Caption feature. To relate them to headings, you can use styles to create a List of Figures. This list can be inserted from the References Tab by selecting Insert Table of Figures.

EX6:

3-from the references tab , we can insert a table of Contents what is a table of contents and how is related in the styles in the document ? how can a table of contents be updated?

Response: 
A Table of Contents (TOC) lists the main sections and page numbers of a document and is based on heading styles like Heading 1 and Heading 2. To update the TOC after changes, go to the References Tab and select Update Table, choosing to update either page numbers only or the entire table.
